# TAMAVERSE — prototipe lokal

Game pet RPG berbasis HTML, CSS, dan JavaScript tanpa dependensi. Buka `index.html` pada preview browser yang tersedia untuk mulai bermain. Pada Android, buka alamat preview proyek dari browser/editor; layout dibuat untuk layar ponsel.

## Yang sudah berfungsi
- Profil guest lokal, telur starter gratis, penamaan pet, dan penyimpanan otomatis ke `localStorage`.
- Perawatan pet (feed, play, clean, sleep, train), XP/level, dan notifikasi.
- Koleksi 12 spesies, pergantian pet aktif, telur gacha berbayar koin/gem, telur harian, pity, riwayat, dan duplikat menjadi fragmen.
- Battle turn-based melawan AI lokal, skill, defend, item, hadiah, quest harian, toko/inventori sederhana, ranking contoh, profil, dan reset save dengan konfirmasi.
- Navigasi mobile dan fallback browser biasa. Integrasi Telegram Mini App belum diaktifkan.

## Catatan penting
Progres, gacha, battle, rating, dan ranking hanya tersimpan di perangkat/browser ini; semuanya dapat diubah melalui browser dan tidak aman untuk kompetisi online. Ranking adalah contoh/demo, PvP simulasi belum menghubungkan pemain nyata. Telegram login, akun bersama, matchmaking, dan leaderboard global memerlukan backend tepercaya. Tidak ada pembayaran uang sungguhan.

Tarif gacha dasar ditampilkan di halaman Gacha. Dalam egg pool yang tidak punya rarity tertentu, generator memilih salah satu spesies yang tersedia di egg tersebut; pity Rare/Epic disimpan lokal.
