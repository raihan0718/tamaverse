# Tamaverse Main Quest Assets

Koleksi asset untuk Main Quest: The Lost Memories.

- `npcs/` — 6 folder sprite utama NPC. Ekspresi ditunda.
- `locations/` — 6 folder background portrait 9:16.
- `objects/` — 10 folder objek interaktif.
- `ui/` — 10 folder komponen Visual Novel dan Quest.

Art direction: 2D pixel art, pastel fantasy, dreamy dan mysterious. Jaga konsistensi pixel density, palet warna, dan proporsi seluruh asset.
