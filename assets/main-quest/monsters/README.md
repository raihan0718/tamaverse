# Main Quest Monsters

Folder untuk aset monster battle Main Quest Tamaverse.

Letakkan setiap monster sebagai file WebP individual dengan nama berikut:

- `slime-king.webp`
- `forgotten-guardian.webp`
- `forest-guardian.webp`
- `ink-phantom.webp`
- `memory-devourer.webp`
- `hollow-knight.webp`
- `the-first-silence.webp`

Style: 2D pixel art semi-baby fantasy. Satu file untuk satu monster; jangan gabungkan menjadi sprite sheet atau kolase.
